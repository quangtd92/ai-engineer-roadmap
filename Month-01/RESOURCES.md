# Tháng 1 - Tài liệu tham khảo

Chỉ dùng các phần cần thiết cho từng ngày; không cần đọc toàn bộ website.

## Tuần 1

- [Python - Defining Functions](https://docs.python.org/3/tutorial/controlflow.html#defining-functions): function, type hint và docstring.
- [Python - dataclasses](https://docs.python.org/3/library/dataclasses.html): `@dataclass`.
- [Python - Logging HOWTO](https://docs.python.org/3/howto/logging.html): logger, level và format.
- [uv - Working on projects](https://docs.astral.sh/uv/guides/projects/): khởi tạo và chạy project.
- [pytest - Getting Started](https://docs.pytest.org/en/stable/getting-started.html): test đầu tiên.
- [Ruff - Tutorial](https://docs.astral.sh/ruff/tutorial/): lint cơ bản.

## Tuần 2

- [FastAPI - Request Body](https://fastapi.tiangolo.com/tutorial/body/): Pydantic request model.
- [FastAPI - Bigger Applications](https://fastapi.tiangolo.com/tutorial/bigger-applications/): router.
- [FastAPI - Dependencies](https://fastapi.tiangolo.com/tutorial/dependencies/): dependency injection.
- [FastAPI - Handling Errors](https://fastapi.tiangolo.com/tutorial/handling-errors/): `HTTPException` và exception handler.
- [Pydantic - Models](https://docs.pydantic.dev/latest/concepts/models/): validation và serialization.
- [pydantic-settings](https://docs.pydantic.dev/latest/concepts/pydantic_settings/): environment settings.

## Tuần 3

- [FastAPI - Async](https://fastapi.tiangolo.com/async/): khi dùng `async def`.
- [FastAPI - Middleware](https://fastapi.tiangolo.com/tutorial/middleware/): request middleware.
- [HTTPX - Async support](https://www.python-httpx.org/async/): `AsyncClient`.
- [HTTPX - Timeouts](https://www.python-httpx.org/advanced/timeouts/): timeout rõ ràng.
- [uv - Using uv in Docker](https://docs.astral.sh/uv/guides/integration/docker/): Docker image.
- [Docker - Compose](https://docs.docker.com/compose/): compose local.

## Tuần 4

- [PyTorch - Tensors](https://docs.pytorch.org/tutorials/beginner/basics/tensorqs_tutorial.html): shape, dtype, device.
- [PyTorch - Quickstart](https://docs.pytorch.org/tutorials/beginner/basics/quickstart_tutorial.html): Dataset, DataLoader, model mode.
- [PyTorch - no_grad](https://docs.pytorch.org/docs/stable/generated/torch.no_grad.html): tắt gradient khi inference.
- [FastAPI - Response Model](https://fastapi.tiangolo.com/tutorial/response-model/): response có schema.
